#
# Mapping of Imperator Religion Modifier + Deity Passive Effect -> CK3 Effect
#
# This is used for conversion of Holy Sites.
#

# The possible modifier categories are:
## Applies modifiers to all characters of the Faith as long as the barony/county holder's Faith considers this an Eminent Holy Site.
# faith_character_modifier = {
# 	<modifier>
# }

## Applies modifiers to all characters of the Faith as long as the barony/county holder's Faith considers this an Eminent Holy Site. The given modifier(s) are scaled by the given "scale" value.
# faith_character_modifier_scaled = {
# 	scale = holy_site_total_artifact_rarity # Can be any scripted value, but this is the most common.
# 	<modifier>
# }

## Applies modifiers to the county holder of this Holy Site as long as it's their Faith's Holy Site. Works for Regular and Eminent Holy Sites.
# county_holder_character_modifier = {
# 	<modifier>
# }

## Applies modifiers to the county itself. Works for Regular and Eminent Holy Sites. The given modifier(s) are scaled by the given "scale" value.
# county_modifier_scaled = {
# 	scale = holy_site_total_artifact_rarity # Can be any scripted value, but this is the most common.
# 	<modifier>
# }

## An arbitrary parameter/flag set on the Holy Site. Can be referenced anywhere in script using these triggers:
### Barony Scope: 'has_holy_site_parameter'
### Faith Scope: 'controls_holy_site_with_parameter'
### Localization: "holy_site_parameter_<parameter_name>"
# parameters = {
# 	parameter_name
# }

# ~tanner918: When setting up these initial templates, I looked at what the values for each potential Imperator modifier typically would be (since they almost always use scripted values, so they are fairly consistent). Then, I looked at what base game Holy Sites used the given character modifier in CK3 1.19, and how they updated that after BGA, and basically just used the same modifiers, but changed their values around the expected Imperator modifier value. The Holy Site I used as a reference will be left as a comment on each one. After everything is properly setup, these should probably be revisited to make them a little more unique.
